# 🎬 Creo Builder — Посібник користувача

> **Creo Builder** — це інструмент для створення відеокреативів без технічних знань. Ти завантажуєш відео, ШІ ділить його на сцени, ти їх редагуєш і збираєш фінальний ролик. Все в одному місці.

---

## 🗺️ Загальний процес

```
Крок 1          →    Крок 2         →    Крок 3
Create Scenes        Edit Scenes         Generate Video
Завантаж відео       Налаштуй сцени      Збери фінальне відео
та розріж на сцени   та згенеруй їх
```

> 💡 Три кроки завжди видно зверху сторінки. Між ними можна перемикатись у будь-який момент — прогрес не зникне.

---

## Крок 1 — Create Scenes

**Мета:** Завантажити вихідне відео і розбити його на окремі сцени. Або створити сцени вручну з нуля.

---

### Завантаження відео

<!-- EMBED: https://oleksandrshurubura-cmyk.github.io/notion-html/btn-select-creo-file.html -->

Кнопка **Select Creo File** відкриває вікно вибору файлу. Завантаж будь-яке відео (MP4, MOV тощо). Після вибору файлу — натискай **Split scenes from creo**.

> ⚡ **Як працює сплітинг:**
> Система аналізує відео через комп'ютерний зір. Кожен раз коли змінюється ракурс або локація — це нова сцена. Процес займає від кількох секунд до кількох хвилин залежно від довжини відео.

---

### Формат відео (Aspect Ratio)

Обери формат перед сплітингом — він застосовується до всіх сцен.

<!-- EMBED: https://oleksandrshurubura-cmyk.github.io/notion-html/radio-aspect-ratio.html -->

| Кнопка | Формат | Де використовується |
|---|---|---|
| **Portrait (9:16)** | Вертикальне | TikTok, Reels, Stories |
| **Landscape (16:9)** | Горизонтальне | YouTube, десктоп |
| **Square (1:1)** | Квадратне | Facebook, Instagram feed |

---

### Кнопки дій

<!-- EMBED: https://oleksandrshurubura-cmyk.github.io/notion-html/btn-split-scenes.html -->

**Split scenes from creo** — запускає розбивку завантаженого відео на сцени. Кнопка активна тільки коли файл вибрано. Під час процесу показується прогрес-бар.

<!-- EMBED: https://oleksandrshurubura-cmyk.github.io/notion-html/btn-add-empty-scene.html -->

**Add Empty Scene** — додає порожню сцену без відео. Використовуй якщо хочеш створити сцену вручну — завантажиш відео або зображення пізніше на кроці Edit.

<!-- EMBED: https://oleksandrshurubura-cmyk.github.io/notion-html/btn-reset.html -->

**Reset** — видаляє всі сцени і скидає форму. Використовуй якщо хочеш почати спочатку з іншим відео.

---

### Load from Task

> 🔄 **Load from Task**
> Дозволяє відновити сцени з попереднього запуску. Якщо ти вже робив сплітинг або регенерацію раніше — знайди потрібний таск у розділі **Tasks** (фільтр: `split_scenes` або `regenerate_scene`), скопіюй його **Task ID** і встав сюди.
>
> - З `split_scenes` таску — підвантажаться всі сцени від того сплітингу
> - З `regenerate_scene` таску — підвантажиться конкретна сцена

---

### Список сцен

Після сплітингу сцени з'являться внизу у вигляді сітки карток. На кожній картці:
- Превью відео (або заглушка якщо ще немає)
- Порядковий номер сцени
- 🗑️ Кнопка видалення сцени

> 💡 Порядок сцен = порядок у фінальному відео. Пам'ятай це при редагуванні.

---

## Крок 2 — Edit Scenes

**Мета:** Налаштувати кожну сцену — додати войсовер, заголовок, текст, та запустити генерацію через ШІ.

---

### Загальне налаштування (General Configuration)

> Розділ, що згортається. Натисни щоб відкрити ▸

Тут задаються параметри, які **застосовуються до всіх сцен одразу**. Якщо зміниш щось тут — всі сцени автоматично оновляться.

| Параметр | Що робить |
|---|---|
| **Headline Position** | Де на відео відображається текст заголовку: зверху, по центру або знизу |
| **Custom Font** | Завантаж власний шрифт (.ttf/.otf) — він буде використаний для всіх заголовків |
| **Voiceover Option** | Тип озвучки: з войсовером чи без |
| **ElevenLabs Voice** | Вибір голосу з готового списку для озвучки |

> 💡 Ці налаштування — це "шаблон" для всіх сцен. Але у кожній сцені можна окремо перевизначити будь-який параметр.

---

### Script to Scenes

> Розділ, що згортається. Натисни щоб відкрити ▸

Дозволяє написати повний текст скрипту і автоматично розподілити його по сценах.

**Як користуватись:**
1. Введи текст скрипту у текстове поле
2. Розбий текст на блоки — кожен блок = один заголовок для однієї сцени
3. Натисни кнопку застосувати — текст розподіляється по сценах по порядку

> ⚠️ Кількість блоків у скрипті має відповідати кількості сцен. Перевір перед застосуванням.

---

### Bulk Attach Images

> Розділ, що згортається. Натисни щоб відкрити ▸

Завантаж кілька зображень одразу — вони автоматично розподіляться по сценах по порядку (1 зображення = 1 сцена).

> Корисно коли у тебе є набір статичних зображень замість відео.

---

### Кнопки у списку сцен

<!-- EMBED: https://oleksandrshurubura-cmyk.github.io/notion-html/btn-generate-all.html -->

**Generate all (N)** — запускає генерацію всіх сцен які мають заповнений контент (відео або зображення + войсовер). У дужках — кількість готових до генерації сцен. Після натискання система відправляє задачі на сервер. Кожна сцена генерується окремо — можеш продовжувати роботу поки вони обробляються.

<!-- EMBED: https://oleksandrshurubura-cmyk.github.io/notion-html/btn-generate-selected.html -->

**Generate selected (N)** — те саме що Generate all, але тільки для вибраних сцен. Щоб вибрати сцени — постав галочку на кожній потрібній. У дужках — кількість вибраних готових сцен.

<!-- EMBED: https://oleksandrshurubura-cmyk.github.io/notion-html/btn-backup-scenes.html -->

**Backup Scenes** — зберігає поточний стан всіх сцен в резервну копію в браузері. Використовуй перед великими змінами. При наступному відкритті сторінки сцени автоматично відновляться.

---

### Trim (обрізка сцени)

<!-- EMBED: https://oleksandrshurubura-cmyk.github.io/notion-html/btn-trim.html -->

**Trim** — відкриває модальне вікно де можна обрізати відео сцени — вибрати початок і кінець фрагменту. Зміни зберігаються тільки для цієї сцени.

---

## Крок 3 — Generate Video

**Мета:** Зібрати всі згенеровані сцени у фінальне відео, додати музику та кінцівку.

---

### Музика

Завантаж аудіо файл як фонову музику для відео. Після завантаження доступна:
- Прослуховування треку прямо на сторінці
- **Регулювання гучності** (Music Volume) — повзунок у dB. За замовчуванням -18 dB (тихий фон).

> 💡 Рекомендуємо тримати музику тихо (-18 dB і нижче) щоб вона не заглушала войсовер.

---

### Include Captions

<!-- EMBED: https://oleksandrshurubura-cmyk.github.io/notion-html/toggle-captions.html -->

Автоматично додає субтитри на фінальне відео. Субтитри генеруються на основі войсоверу кожної сцени.

- **Увімкнено** — субтитри є на відео (рекомендовано)
- **Вимкнено** — відео без субтитрів. Але для цього кожна сцена повинна мати **clean відео** (інакше кнопка Merge буде заблокована)

---

### Creo Tail (кінцівка)

Секція внизу списку сцен. Тут можна додати **CTA відео** — окреме відео-кінцівка яка буде додана в кінець фінального ролику.

Доступні варіанти:
- **Біла CTA** — готова заготовка
- **Зелена CTA** — готова заготовка

---

### Merge Scenes

<!-- EMBED: https://oleksandrshurubura-cmyk.github.io/notion-html/btn-merge-scenes.html -->

Запускає збирання фінального відео. Система:
1. Завантажує всі матеріали на сервер
2. З'єднує сцени по порядку
3. Накладає музику і субтитри
4. Додає кінцівку (якщо вибрана)

Під час процесу показується прогрес-бар. Після завершення — відео з'явиться справа від списку сцен для перегляду.

> ⚠️ Якщо Merge Scenes заблокована — переконайся що включені `Include captions`, або що всі сцени мають clean відео.

---

## 🔧 Task Details (кнопка у верхній панелі)

<!-- EMBED: https://oleksandrshurubura-cmyk.github.io/notion-html/dropdown-task-details.html -->

Кнопка **Task Details** з'являється у правій частині верхньої панелі CreoBuilder після того як були запущені будь-які задачі.

| Пункт меню | Коли з'являється | Що робить |
|---|---|---|
| **Refresh scene urls** | Завжди | Оновлює посилання на відео в сценах. Корисно якщо відео в сценах перестали відтворюватись (посилання мають термін дії) |
| **Split Scenes →** | Після сплітингу | Переходить до деталей таску розбивки на сцени |
| **Merge Scenes →** | Після мержу | Переходить до деталей таску збирання відео |
| **Download cleans ↓** | Коли є clean відео | Завантажує всі "чисті" версії сцен одним кліком |

---

### Що таке Clean відео?

> **Clean** — це "чисте" відео або зображення яке генерує ШІ. Без накладеного тексту, без музики, без субтитрів. Це вихідний матеріал у найчистішому вигляді.
>
> Clean файли зберігаються і використовуються для:
> - 📦 Архівування та повторного використання
> - 🏷️ Тегування елементів
> - 🔄 Переробки того самого матеріалу з новими параметрами (інший текст, інша музика тощо)
>
> Кнопка **Download cleans** дозволяє скачати всі clean файли поточного проекту одним кліком.

## 📋 Розділ Tasks

Tasks — це **архів і журнал** всіх задач які ти коли-небудь запускав. Сюди заходять коли потрібно щось відновити або перевірити статус.

> 💡 В рамках Creo Builder вас цікавлять три типи задач (фільтр **Type**):
> - `split_scenes` — розбивка відео на сцени
> - `regenerate_scene` — генерація окремої сцени
> - `merge_scenes` — збирання фінального відео

---

### Статуси задач

<!-- EMBED: https://oleksandrshurubura-cmyk.github.io/notion-html/status-tags.html -->

| Статус | Що означає |
|---|---|
| **CREATED** | Задача створена, очікує на обробку |
| **QUEUED** | Задача в черзі, обробляється прямо зараз |
| **SUCCESS** | Задача виконана успішно |
| **ERROR** | Виникла помилка при виконанні |

> Система автоматично оновлює статуси — тобі не потрібно вручну оновлювати сторінку.

---

### Картка задачі

- **Task ID** — унікальний ідентифікатор задачі (клікабельний, веде на деталі)
- **Дата і час** створення
- **Час обробки** — скільки тривала задача
- **Статус** — з кольоровою позначкою

<!-- EMBED: https://oleksandrshurubura-cmyk.github.io/notion-html/btn-view-details.html -->

**View Details** — перейти до повних деталей задачі.

<!-- EMBED: https://oleksandrshurubura-cmyk.github.io/notion-html/btn-download-video.html -->

**Download Video** — з'являється тільки для успішних задач де є відео.

---

### Детальний вигляд задачі

**Основна інформація:**
- Task ID (з кнопкою копіювання)
- Тип задачі
- Статус
- Дата створення та завершення
- Час обробки
- Опис помилки (якщо є)

**Resources (Ресурси):**
Всі файли пов'язані з цією задачею — вхідні та вихідні. Для кожного ресурсу:
- Назва та тип
- Resource ID
- GCS Path (шлях до файлу в хмарному сховищі)
- **Open Resource** — відкрити файл у новій вкладці

> 📦 **Навіщо це потрібно?**
> Task Details — це гарантія що твої матеріали не зникнуть. Навіть якщо щось пішло не так у браузері — все зберігається в задачах на сервері. По Task ID ти завжди можеш відновити роботу через **Load from Task** на кроці Create Scenes.

---

### Як відновити роботу через Tasks

1. Зайди у розділ **Tasks**
2. Постав фільтр **Type** → `split_scenes` (або `regenerate_scene`)
3. Знайди потрібну задачу зі статусом **SUCCESS**
4. Клікни на **Task ID** → скопіюй його 📋
5. Повернись у **Creo Builder** → Крок 1 → **Load from Task**
6. Встав Task ID → підтверди

Сцени з того запуску завантажаться автоматично.

## 🚀 Типовий сценарій з нуля

**1.** Відкрий **Creo Builder** → Ти на Кроці 1 (Create Scenes)

**2.** Натисни **Add Empty Scene** — з'явиться порожня сцена (або кілька якщо потрібно більше)

**3.** Перейди на **Крок 2** (Edit Scenes)

**4.** Відкрий **General Configuration** → налаштуй позицію заголовку, шрифт, войсовер та голос

**5.** Відкрий **Script to Scenes** → введи текст скрипту, розбий на блоки по сценам, застосуй

**6.** Перевір кожну сцену — текст правильно розподівся?

**7.** Додай відео або зображення до кожної сцени

**8.** Якщо потрібно — обріж відео через кнопку **Trim**

**9.** Натисни **Generate all** — ШІ починає генерувати сцени

**10.** Дочекайся поки всі сцени мають статус ✅ (можеш моніторити в Tasks → `regenerate_scene`)

**11.** Перейди на **Крок 3** (Generate Video)

**12.** Завантаж фонову музику (якщо потрібна), налаштуй гучність

**13.** Перевір чи увімкнені **Include captions**

**14.** Вибери **Creo Tail** (кінцівка відео)

**15.** Натисни **Merge Scenes** → чекай на результат

**16.** Готово — фінальне відео з'явиться справа 🎉
